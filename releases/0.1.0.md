# QS Mind One 0.1.0

<!-- en -->
**This is a test build** for the QS Mind team (stage 1). It is not a public release yet.

The first QS Mind One: the Lead QS and the team it builds for each job, a first launch you can skip step by step, tender folder import with the "I understood this" card, close and archive a project, encrypted backups with your Backup key, and Usage Stats that send nothing until you say yes.

**Download**

- Windows (64-bit): [QS-Mind-One_x64-setup.exe](https://github.com/qs-mind/one/releases/download/v0.1.0/QS-Mind-One_x64-setup.exe)
- macOS, Apple silicon: [QS-Mind-One_aarch64.dmg](https://github.com/qs-mind/one/releases/download/v0.1.0/QS-Mind-One_aarch64.dmg)
- macOS, Intel: [QS-Mind-One_x64.dmg](https://github.com/qs-mind/one/releases/download/v0.1.0/QS-Mind-One_x64.dmg)
- Linux (64-bit): [QS-Mind-One_amd64.AppImage](https://github.com/qs-mind/one/releases/download/v0.1.0/QS-Mind-One_amd64.AppImage)

`SHA256SUMS.txt` lists the checksum of every file.

**Installing a test build**

The installers are not signed with a paid certificate yet, so your computer warns you once.

- Windows: run the installer. If Windows says it protected your PC, choose **More info**, then **Run anyway**.
- macOS (13 or newer): open the DMG and drag QS Mind One to Applications. The first time you open it, macOS stops it: open **System Settings → Privacy & Security**, and choose **Open Anyway** next to QS Mind One.
- Linux: make the AppImage executable (right-click → Properties → Allow executing, or `chmod +x QS-Mind-One_amd64.AppImage`), then open it.
